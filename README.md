# KuXia-App

Release channel for **KuXia (repoxy)** official binaries.

- Source repository: <https://gitee.com/KylinLab/KuXia>
- This repository hosts release assets only; it does not carry source code.
- Download the asset for your platform from the Releases tab
  (`kuxia-<version>-<platform>.tar.gz` / `.zip`, each with a `.sha256` sidecar).
